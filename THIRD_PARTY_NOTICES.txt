NVIDIA CUDA runtime components (Linux CUDA packages only)
---------------------------------------------------------

Linux packages staged from a CUDA-enabled native build include unmodified
shared libraries resolved from that build's dependencies:

  * libcudart.so.12 from NVIDIA cuda_cudart 12.8.57
  * libcublas.so.12 and libcublasLt.so.12 from NVIDIA libcublas 12.8.3.14
  * libnccl.so.2 from NVIDIA NCCL 2.25.1, when the build links NCCL

CPU-only Linux packages do not include these shared libraries. The NVIDIA
driver library libcuda.so.1 is not bundled; CUDA packages require a compatible
NVIDIA driver supplied by the host system.

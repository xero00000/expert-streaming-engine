# ESE 0.2.1 — Bigger AI. The PC you already own.

This update makes ESE easier to discover, improves expert-cache reuse and
recovery, and brings a complete set of Linux and Windows desktop packages.

## What's improved

- **A clearer first start.** A refreshed project page and new beginner guide take
  you from choosing a package to your first local conversation.
- **Better use of model memory.** Compatible expert-cache payloads can be reused
  across layer layouts, and independent RAM-cache reads can overlap within
  their limits. Memory accounting and failed-request recovery are improved.
- **More dependable Windows installation.** Both installers include CUDA and a
  separate CPU runtime, plus the required Microsoft C++/OpenMP components. The
  installed app needs neither Python nor the CUDA toolkit.
- **Updates that keep your package choice.** Linux AppImage updates preserve the
  CPU or CUDA variant. AppImage and Windows NSIS updates verify cryptographic
  signatures; DEB/RPM packages update through their package manager.

Check your file against **SHA256SUMS** from this release before installing.
Linux CUDA requires a compatible NVIDIA driver. Windows includes a CPU fallback.
Windows installers do not carry Authenticode signatures; the separate NSIS
updater signature does not provide Windows publisher identity.

## Verified scope

The packages passed recorded local build, payload/dependency and installation
checks. Scoped Linux inference, Windows CPU fallback, short reference-output
checks and actual signed AppImage/NSIS installed updates pass. These are local
qualification results; they do not imply a separate hosted build qualification.

Physical Windows NVIDIA inference is deferred and remains unqualified. Extended
context/concurrency and soak checks are also deferred. Experimental Qwen
admission remains disabled in production builds. Model compatibility, available
memory and storage affect performance; no general throughput promise is made.

ESE v0.2.1 improves expert-cache reuse, memory accounting and recovery, and server request handling. Windows packages include a separate CPU runtime so the launcher can run without an NVIDIA driver.

Downloads: choose the Linux `cpu` package for CPU operation or the `cuda` package for NVIDIA acceleration. Windows MSI and setup EXE packages include both runtimes. Windows installers do not carry Authenticode signatures; NSIS updates have a separate cryptographic updater signature.

Linux CPU and CUDA packages passed native payload, dependency and installed-package checks. Both Windows installers pass local installation, CPU fallback and short reference-output checks. The real signed NSIS update also passes failure controls, reinstallation and post-update startup. Physical Windows GPU model inference remains unqualified; hosted CI does not replace that hardware gate.

Experimental Qwen support remains disabled in production builds. Speed parity has not been achieved, and this release makes no general throughput claim. Long-context and extended soak qualification remain incomplete.

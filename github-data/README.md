# Historical upstream GitHub export

This directory is a read-only archive of 626 issues, pull requests, and
discussions exported from `ikawrakow/ik_llama.cpp`. Individual records retain
their original upstream links and timestamps. The archive was already present
when ESE `v0.1.2` was documented on 2026-08-24; the original extraction date is
not encoded separately.

These files are historical research/provenance material, not current ESE
documentation, support policy, release status, or installation guidance. Their
claims and links may be stale, and they are intentionally excluded from ESE's
documentation link and version checks.

Current user and contributor guidance begins in the repository
[`README.md`](../README.md), [`docs/`](../docs), and
[`CONTRIBUTING.md`](../CONTRIBUTING.md).

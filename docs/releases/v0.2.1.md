ESE v0.2.1 improves expert-cache reuse, memory accounting and recovery, and server request handling. Windows packages include a separate CPU runtime so the launcher can run without an NVIDIA driver.

Downloads: choose the Linux `cpu` package for CPU operation or the `cuda` package for NVIDIA acceleration. Windows MSI and setup EXE packages include both runtimes. Windows installers are unsigned.

Linux CPU and CUDA packages passed native payload, dependency and installed-package checks. Windows verification includes CPU executable and launcher checks; Windows GPU model inference and installer execution are not qualified by the hosted CI checks.

Experimental Qwen support remains disabled in production builds. Speed parity has not been achieved, and this release makes no general throughput claim. Long-context and extended soak qualification remain incomplete.
